# HTTP headers

HTTP headers are the additional information to the website some information like request type , meta data, etc are shown in HTTP headers  


## Why should we be having a "X" Appended to our headers? 
Historically, "X-" stood for "experimental" or "extension." Developers were told to use it for any custom, non-standard headers to ensure they wouldn't clash with future official HTTP headers

But now there is no need to appending a "X-" prefix becuase the Internet Engineering Task Force (IETF) officially deprecated the "X-" prefix in 2012 through RFC 6648.
